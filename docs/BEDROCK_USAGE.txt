RemoteAgent — dzienne użycie Amazon Bedrock
============================================

Wartości są migawką lokalnej telemetrii klientów, a nie fakturą AWS. Koszt
Claude CLI jest estymacją według stawek zapisanych przez OpenCode dla modelu
US Claude Opus 4.8: input $5/M, output $25/M, cache read $0.50/M i cache write
$6.25/M tokenów. Retry odrzucone przed zapisaniem telemetrii mogą nie być
widoczne; ostateczne rozliczenie należy porównać z AWS Cost Explorer.

Metoda pomiaru
--------------

- OpenCode: dokładna suma dzisiejszych rekordów roli assistant z lokalnej bazy
  ~/.local/share/opencode/opencode.db; koszt pochodzi z pola cost klienta.
- Claude CLI: dzisiejsze pliki JSONL projektu w ~/.claude/projects; rekordy
  zdeduplikowane globalnie po message.id, następnie zsumowane pola usage.
- Cache read i cache write są tokenami rozliczeniowymi i wchodzą do kosztu.
- Kolejne uruchomienia tego samego dnia wymagają zastąpienia dziennej migawki
  nowymi sumami, a po zmianie daty — dopisania nowej sekcji dnia.
