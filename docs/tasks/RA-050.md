# RA-050 — Codex CLI subscription adapter

**Status:** DONE
**Zależy od:** RA-049
**Milestone:** M10 — `ADR-0016`

## Cel

Uruchamiać Engineering przez oficjalne `codex exec` zalogowane kontem ChatGPT,
bez OpenAI API key i bez poszerzenia istniejącej authority.

## Kryteria akceptacji

1. Adapter wywołuje wyłącznie canonical, wspierane `codex` i pinuje wersję,
   model/profile, sandbox, permissions oraz JSON event mode.
2. Auth preflight dowodzi ChatGPT subscription login i odrzuca API-key mode przed
   operation STARTED.
3. JSONL parser jest strict, bounded i mapuje usage, session, tool/event outcome,
   quota, auth, cancel i malformed output bez zapisu reasoning/prose.
4. Built-in shell/write/network są deny-by-default; write-capable role korzysta
   wyłącznie z code-owned bounded bridge/receipt boundary.
5. Przerwanie, timeout i utrata lease kończą proces tree i nie tworzą success.
6. Fake-binary tests pokrywają split chunks, stderr, malformed JSON, quota,
   version drift, forged usage/session i dokładne argv/env.
7. Mutation checks czerwienią auth source, permission/sandbox, parser binding,
   cancellation i tool-boundary bypass.
8. Pełna niecache'owana bramka kończy się exit `0`; live call pozostaje opt-in.
