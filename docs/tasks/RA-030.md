# RA-030 — Produkcyjne wpięcie reconcile Jiry (single-owner API token)

## Goal

Uczynić pętlę Jira → Discord **uruchamialną produkcyjnie**: reconcile handler zarejestrowany w
`worker main()` z żywym tokenem, task w `scheduler main()`, provisioning connectiona — tak, żeby
zmiana na boardzie Jiry rzeczywiście dawała wiadomość na Discordzie przez uruchomione procesy.

## Dlaczego ten task istnieje

RA-029 zbudował routing outboxu i seam joba `jira.reconcile`, ale — jak `jira.webhook.renewal` —
handler nie jest wpięty w `main()`, bo wymaga tokenu. Model auth rozstrzygnięty w
[ADR-0010](../decisions/ADR-0010-single-owner-jira-api-token.md): **personal API token + Basic**
(system jednego właściciela; OAuth 3LO świadomie pominięty i niezbudowany).


## Kryteria akceptacji

- **AC1:** Reużywalny transport Basic (`email`+`token` → `Authorization: Basic`), `getAccessToken`
  z env (token zerowany po użyciu). `worker main()` rejestruje handler `jira.reconcile` gdy
  `JIRA_*` obecne; bez nich — nie rejestruje (fail-closed do DLQ jak renewal).
- **AC2:** `scheduler main()` rejestruje task `jira.reconcile` z projektami z env; brak projektów
  → brak taska (i loud log, jak przy pustej liście).
- **AC3:** Idempotentne provisioning ownera + connectiona Jira (provider `jira`, alias, z env),
  żeby correlate scope przechodził. Bezpieczne przy wielokrotnym starcie.
- **AC4:** Env-kontrakt parsowany osobno (walidowalny bez DB, bez sekretu, bez sieci). Token nie
  pojawia się w logach ani błędach (canary w teście).
- **AC5:** Bramka zielona: podsystemy dotknięte + pełne repo pod Node 24 (`RA_REQUIRE_POSTGRES=1`),
  typecheck/build/lint/format, liczba przebiegów.

## Świadome zawężenia

- Bez OAuth 3LO, bez refreshu, bez multi-connection (ADR-0010).
- `CredentialVault` nie jest warstwą persystencji na tej ścieżce (env jest źródłem tokenu).
- Deploy do CDK (scheduler jako serwis) — osobny krok AWS, nieweryfikowalny lokalnie.
- Live end-to-end (realna wiadomość na Discordzie) wykonuje właściciel z credentialami; dowód
  automatyczny to testy kompozycyjne + reconcile→correlate→outbox z RA-029.
