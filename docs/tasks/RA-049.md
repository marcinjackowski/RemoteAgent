# RA-049 — Provider-neutral subscription model runtime

**Status:** BLOCKED_BY_DEPENDENCIES
**Zależy od:** RA-048
**Milestone:** M10 — `ADR-0016`

## Cel

Oddzielić Engineering contracts, structured completion, budgets i journaling od
Bedrock Converse oraz ustanowić bezpieczną granicę uruchamiania oficjalnych
klientów subskrypcyjnych.

## Kryteria akceptacji

1. Provider-neutral contracts obejmują role, model identity, usage, normalized
   events, outcome i config digest bez typów AWS/Bedrock.
2. Strict deployment config definiuje nazwane profile tylko dla `codex_cli` i
   `claude_code`; `bedrock`, `opencode`, API endpoint i API key są odrzucane.
3. Process boundary używa canonical executable + argv, bounded stdin/stdout,
   timeout/cancel/process-tree kill oraz secret-free environment.
4. Subscription-auth preflight jest code-owned i fail-closed; RemoteAgent nie
   czyta ani nie zapisuje vendor credentials.
5. Production Engineering nie ma automatycznego Bedrock defaultu ani fallbacku.
6. Recovery descriptor wiąże provider/profile/client/model/config przed invoke.
7. Mutation checks czerwienią provider allowlist, API-key rejection, argv/env
   isolation, timeout kill, output bound i Bedrock-default disconnect.
8. Pełna niecache'owana bramka kończy się exit `0`.
