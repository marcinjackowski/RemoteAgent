# RA-045 — Kwalifikacja iOS/Xcode na sondermind-ios

**Status:** BLOCKED_BY_DEPENDENCIES  
**Zależy od:** RA-047
**Milestone:** M9 (iOS Qualification) — `ADR-0011`, `ADR-0014`

## Cel

Skonfigurować i jawnie uruchomić Engineering Control Plane na macOS/Xcode dla
małego, zaakceptowanego taska w `sondermind-ios`, bez push/MR i bez udawania, że
profil generic sandbox odpowiada wymaganiom Xcode/SPM.

## Zakres

- Repo-specific gate catalog: build, test, lint/format i opcjonalna inspekcja
  simulator/UI, rozwiązywane jako executable+argv.
- Profile DerivedData, simulatorów, cache/dependency roots, network policy,
  timeoutów i redakcji ścieżek/sekretów.
- Live Bedrock + Postgres + worktree + local commit na branchu case'a.
- Przed smoke właściciel akceptuje dokładny task i dozwolony lokalny side effect.
- Smoke używa produkcyjnego approval ingressu i cross-fence recovery z RA-046/RA-047; ręczne
  inserty DB albo fixture-only grant nie są dowodem live composition.

## Kryteria akceptacji

1. Environment preflight zapisuje wersje Xcode/Swift, simulator destination,
   base SHA i config digest; brak wymagania daje `BLOCKED`, nie skip/pass.
2. Baseline i required gates uruchamiają się rzeczywiście; każdy ma exit code,
   duration, log digest i tree/config binding.
3. Pełny cykl kończy się tylko po zaakceptowanym designie, pionowych slices,
   gates, review i lokalnym commit receipt.
4. Celowo czerwony test iOS nie może zakończyć runu jako `COMPLETED`; po
   przywróceniu ten sam gate kończy się exit code `0`.
5. Host paths, credentials i prywatne dane nie pojawiają się w model context,
   logach ani dokumentach dowodowych; canary mutation dowodzi redakcji.
6. Push/MR/merge pozostają nieosiągalne.
7. Raport live smoke zapisuje dokładne komendy, exit codes, commit SHA, diff i
   ograniczenia profilu Xcode; `workflow:validate` kończy się exit code `0`.

## Warunek startu

Task nie uruchamia się automatycznie po M8. Wymaga gotowego lokalnego środowiska
macOS/Xcode/AWS oraz potwierdzonego przez właściciela małego zadania docelowego.
