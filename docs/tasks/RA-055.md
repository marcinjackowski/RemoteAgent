# RA-055 — Live Codex Engineering rerun na MOBL-2023

**Status:** IN_PROGRESS
**Zależy od:** RA-054
**Milestone:** M10 — live qualification po `ADR-0016`

## Cel

Uruchomić pełny, izolowany Engineering Control Plane dla zaakceptowanego taska
MOBL-2023 w `sondermind-ios`, kierując wszystkie role jawnie do oficjalnego
`codex` zalogowanego subskrypcją ChatGPT. Zachować wynikowy worktree i lokalny
commit do inspekcji właściciela; nie używać Jira, Discorda, Bedrocka, Claude,
OpenCode ani API key. Nie pushować ani nie tworzyć MR dla niezweryfikowanego
worktree iOS. Właściciel osobno zatwierdził `2026-09-04` checkpoint commit i
push zmian samego repozytorium RemoteAgent, aby kolejna sesja mogła wykonać
niezależny audyt i kontynuować live qualification.

## Kryteria akceptacji

1. Preflight potwierdza canonical Codex CLI, login ChatGPT, jawny model
   `gpt-5.6-sol`, canonical Xcode oraz czysty seed MOBL-2023 na zapisanym SHA.
2. Każda rola `DESIGNER`, `IMPLEMENTER`, `REVIEWER`, `VERIFIER` używa tego samego
   jawnego profilu Codex bez fallbacku; invocation ID i journal są nowe.
3. Produkcyjna ścieżka `createWorkerHandlers -> SupervisorRuntime ->
   createProductionEngineeringRuntimePort` wykonuje dokładny objective MOBL-2023
   z realnym PostgreSQL, izolowanym Git worktree i rzeczywistymi gates Xcode.
4. Sukces wymaga designu, server-owned slices, rzeczywistego diffu, wymaganych
   gate receipts, fresh review, final verification i dokładnie jednego lokalnego
   commit receipt. Nieudany przebieg pozostaje jawnym `FAILED/BLOCKED`, nigdy
   pozornym sukcesem.
5. Source checkout, seed worktree i wcześniejsze worktree pozostają bez zmian.
   Nowy wynikowy worktree oraz commit nie są usuwane.
6. Osobny content-free journal zapisuje etapy, decyzje, tool outcomes, gates,
   provider-reported usage i sumę tokenów bez promptu, prose modelu, CoT,
   sekretów i host paths. Raport porównuje rzeczywiste użycie z początkową
   estymatą `180k–450k`, empirycznie skorygowaną estymatą `800k–1.50m` oraz
   limitami `750k/1.2m/1.8m`.
7. Jira, Discord oraz push/MR/merge worktree iOS pozostają nieosiągalne; pełna
   niecache'owana bramka RemoteAgent oraz `workflow:validate` kończą się exit
   code `0` przed audytem `PASS`. Dozwolony jest wyłącznie zatwierdzony przez
   właściciela checkpoint push kodu RemoteAgent.
