# RA-051 — Claude Code subscription adapter

**Status:** BLOCKED_BY_DEPENDENCIES
**Zależy od:** RA-050
**Milestone:** M10 — `ADR-0016`

## Cel

Uruchamiać Engineering przez oficjalne `claude -p` zalogowane subskrypcją
Claude, bez Anthropic API key, Bedrock/Vertex/Foundry i bez OpenCode.

## Kryteria akceptacji

1. Adapter wywołuje wyłącznie canonical, niezmodyfikowane `claude`, pinuje
   wspierany zakres wersji, model/profile, permissions i structured event mode.
2. Auth preflight dowodzi subscription OAuth oraz odrzuca `ANTHROPIC_API_KEY`,
   auth token i cloud-provider mode przed operation STARTED.
3. User/project settings, hooks, MCP i tools są izolowane; dostępny jest tylko
   code-owned per-invocation surface wymagany przez rolę.
4. Stream/JSON parser jest strict i mapuje usage, session, quota, auth, cancel,
   malformed output oraz partial result bez credential/prose leakage.
5. Recovery i cancellation używają exact session/profile identity; brak quota
   nigdy nie przełącza automatycznie na API credits albo inny provider.
6. Fake-binary tests pokrywają credential precedence, version drift, settings
   injection, malformed events, timeout/process-tree kill i forged identity.
7. Mutation checks czerwienią OAuth proof, API-key/cloud rejection, settings/tool
   isolation, parser binding i no-fallback.
8. Pełna niecache'owana bramka kończy się exit `0`; live call pozostaje opt-in.
