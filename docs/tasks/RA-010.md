# RA-010 — Isolated workspace runner

## Goal

Zapewnić izolowany, odzyskiwalny workspace dla każdego coding case.

## Scope

- `WorkspaceRunner` interface niezależny od lokalnego Dockera/AgentCore/ECS;
- lokalny adapter: repository mirror + Git worktree w dedykowanym sandboxie;
- mapowanie case -> repo allowlist -> base SHA -> workspace -> branch intent;
- filesystem confinement, CPU/RAM/time limits i network deny-by-default;
- kontrolowany lifecycle create/resume/snapshot/destroy;
- tree digest, dirty-state detection i immutable operation log;
- single-writer fencing z RA-004;
- cleanup bez możliwości wskazania szerokiej/niezweryfikowanej ścieżki.

## Out of scope

Model file tools, test semantics, Git commit/push i produkcyjny AgentCore adapter.

## Acceptance criteria

1. Dwa cases tego samego repo mają rozłączne worktrees i zmiany.
2. Workspace nie może czytać/zapisywać poza przydzielonym rootem.
3. Stary writer z nieważnym fencing tokenem nie może zmienić workspace.
4. Restart odtwarza mapping i wykrywa clean/dirty/ambiguous state.
5. Destrukcyjny cleanup odrzuca root, parent workspace i symlinki wychodzące.
6. Model nie otrzymuje credentiali repozytorium ani host filesystem paths.

## Required verification

- integration tests dwóch worktrees i tego samego repo;
- escape/symlink/path traversal tests;
- kill/restart tests podczas modyfikacji;
- resource timeout i network policy tests.

## Audit focus

Sandbox escape, destructive path safety, izolacja cases, recovery dirty tree i
faktyczne egzekwowanie single-writer.
