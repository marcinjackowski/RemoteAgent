# RA-053 — Subscription-provider qualification and Bedrock retirement

**Status:** DONE
**Zależy od:** RA-052
**Milestone:** M10 — `ADR-0016`

## Cel

Porównać Codex i Claude na identycznym, opt-in Engineering zadaniu oraz usunąć
Bedrock/OpenCode z aktywnej konfiguracji i zależności produktu.

## Kryteria akceptacji

1. Deterministyczna qualification suite uruchamia wszystkie cztery kombinacje
   implementer/reviewer na tym samym seed/objective/gates bez live providerów.
2. Każdy opt-in live run ma osobny worktree/journal i jawnie wybrany route;
   żadnego push, MR, Jira ani Discord bez osobnej zgody.
3. Raport porównuje outcome, gate/review attempts, elapsed time, provider usage,
   changed paths/diff digest i commit SHA bez promptu, prose ani CoT.
4. Brak subscription quota/auth kończy tylko dany run jako bounded refusal;
   nie uruchamia API key, Bedrock, OpenCode ani drugiego providera.
5. Production Engineering nie importuje ani nie konstruuje Bedrock transportu;
   stare env vars nie wpływają na route, a OpenCode jest odrzucane schematem.
6. Po potwierdzeniu braku konsumentów usunięte są Engineering-only AWS Bedrock
   dependencies i historyczne config defaults; ewentualny wspólny legacy kod ma
   jawnego właściciela poza Engineering albo zostaje usunięty.
7. Mutation checks czerwienią każdy route disconnect, hidden fallback, stale
   Bedrock env influence, OpenCode acceptance oraz raport bez exact identity.
8. Pełna niecache'owana bramka i audyt całego M10 kończą się exit `0`/`PASS`.
