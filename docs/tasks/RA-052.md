# RA-052 — Configurable Engineering role routing and recovery

**Status:** READY
**Zależy od:** RA-051
**Milestone:** M10 — `ADR-0016`

## Cel

Pozwolić właścicielowi wybierać profile Codex/Claude osobno dla każdej roli i
porównywać kombinacje bez zmiany code authority albo recovery semantics.

## Kryteria akceptacji

1. Strict config mapuje `DESIGNER`, `IMPLEMENTER`, `REVIEWER`, `VERIFIER` na
   nazwane profile; żadna rola nie ma ukrytego providera domyślnego.
2. Test/run może wybrać dowolną dozwoloną kombinację, w tym Codex→Claude,
   Claude→Codex, Codex→Codex i Claude→Claude.
3. Route/profile/model/client/config digest są durable przed call; model, prompt,
   Jira i tool input nie mogą ich zmienić.
4. Restart używa exact pierwotnego route; config drift lub brak klienta blokuje,
   zamiast przełączyć provider albo powtórzyć side effect.
5. Usage budgets i content-free journal są porównywalne między providerami i
   przypisane do roli, slice, attempt i invocation.
6. SupervisorRuntime pozostaje jedynym driverem; adapter ani CLI nie tworzy
   drugiego workflow, commita ani gate authority.
7. Real-PG/fake-client matrix pokrywa dwa slices, correction, review, recovery,
   quota/auth loss, cancellation, stale lease i concurrent cases.
8. Mutation checks czerwienią role swap, config drift, provider fallback,
   missing durable identity, journal misattribution i authority widening.
9. Pełna niecache'owana bramka kończy się exit `0`.
