# RA-014 — Local Git lifecycle

## Goal

Zapewnić bezpieczne i idempotentne operacje branch/status/diff/commit/rebase w
obrębie case workspace.

## Scope

- branch naming i collision handling (`agent/<task>-<slug>`);
- zapis base SHA, target branch, head SHA i repository identity;
- typed tools: status, diff, create branch, stage allowlisted paths, commit;
- commit message policy i powiązanie commitów z case/task;
- wykrywanie istniejącego brancha i bezpieczne resume;
- kontrolowany fetch/rebase oraz konflikt -> durable decision/blocker;
- zakaz force/reset-hard/checkout broad paths i zmian protected branches;
- diff/stat/commit receipts dla checkpointu i review.

## Out of scope

Remote push, GitLab MR i automatyczny merge.

## Acceptance criteria

1. Resume nie tworzy drugiego brancha dla tego samego case.
2. Agent nie może stage/commit plików spoza aktualnego workspace/scope.
3. Commit jest związany z test evidence albo jawnie oznaczony jako unverified.
4. Rebase conflict nie jest automatycznie rozwiązywany bez ponownej analizy.
5. Dirty user changes są wykryte i nigdy cicho nadpisane.
6. Zakazane destrukcyjne komendy mają testy negatywne.

## Required verification

- fixture remote/local repo z collision, resume i conflict;
- tests stage scope i symlink/submodule boundaries;
- commit/tree digest binding tests.

## Audit focus

Ryzyko utraty danych, branch idempotency, commit evidence, submodules i zachowanie
przy konflikcie/starym base SHA.
