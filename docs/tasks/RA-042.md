# RA-042 — Deterministyczny gate runner i evidence binding

**Status:** BLOCKED_BY_DEPENDENCIES  
**Zależy od:** RA-037, RA-038  
**Milestone:** M8 — `ADR-0011`

## Cel

Zbudować bezpieczny adapter wykonania gates nad istniejącymi `test-evidence`,
`workspace-runner` i process runnerem, gdzie wynik powstaje wyłącznie z trwałych
command receipts związanych z dokładnym drzewem i konfiguracją.

## Zakres

- Code-owned gate catalog: ID, `executable`, `argv[]`, workspace-relative cwd,
  required/baseline/test-first flags, timeout, env/network profile i mutable
  outputs.
- Disposable verification workspace/mirror; authoritative worktree read-only.
- Per-command intent/receipt w RA-038 i konserwatywny `EvidenceBundle`.
- Test-first/vacuity, regression, mutation-safety i architecture-policy gates.
- Jawne statusy: `PASSED`, `FAILED`, `TIMED_OUT`, `CANCELLED`,
  `INFRASTRUCTURE`, `AMBIGUOUS`.

## Kryteria akceptacji

1. Nie istnieje raw shell string ani `shell:true`; executable jest allowlisted,
   argv pozostaje tablicą i test command injection nie uruchamia payloadu.
2. Gate działa na disposable workspace; digest authoritative worktree przed i po
   jest identyczny. Zapis poza `mutableOutputs` blokuje wynik; mutation daje RED.
3. Receipt wiąże run/op/gate ID, tree digest, config digest, executable/argv,
   exit code, duration i log digest. Stary albo obcy receipt nie przechodzi.
4. Missing required gate, pusty gate set, brak receipt, niespójny agregat lub
   inny tree digest zawsze daje brak PASS.
5. Test-first/vacuity uruchamia wymagany test na baseline i current tree;
   baseline-green nie jest zaliczanym dowodem nowego testu.
6. Bezpieczeństwo mechanizmu ma realny mutation check RED→GREEN.
7. Timeout/cancel zabija grupę procesów i nie jest mapowany na zwykły test fail;
   crash przed receipt daje `AMBIGUOUS`/`INFRASTRUCTURE` zgodnie z dowodem.
8. Profil sandbox/network jest adapterem; nie udaje jednej uniwersalnej polityki
   dla Xcode. Różnice platformowe są jawne w konfiguracji.
9. Bramka taska i `workflow:validate` kończą się exit code `0`.
